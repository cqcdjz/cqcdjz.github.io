# 个人博客 · 搭建流程步骤

你的博客「无奈朝来寒雨的博客」已经搭好了。这份文档记录它是怎么搭起来的,以及以后怎么维护。

---

## 一、项目结构

```
blog/
├── package.json                # 项目依赖和脚本
├── astro.config.mjs            # Astro 配置(站点地址、输出方式)
├── tsconfig.json               # TypeScript 配置
├── .github/workflows/deploy.yml # GitHub Pages 自动部署配置
├── public/
│   └── favicon.svg             # 浏览器标签页图标
└── src/
    ├── styles/global.css       # 全局样式(深空玻璃主题)
    ├── layouts/BaseLayout.astro # 全局布局(每个页面都套用)
    ├── components/             # 可复用组件
    │   ├── Nav.astro           # 顶部导航栏
    │   ├── Footer.astro        # 页脚
    │   └── PostCard.astro      # 文章卡片
    ├── content/                # 你的内容(写文章就改这里)
    │   ├── config.ts           # 内容字段定义
    │   ├── posts/              # 文章(Markdown)
    │   └── projects/           # 项目(Markdown)
    └── pages/                  # 页面
        ├── index.astro         # 首页
        ├── about.astro         # 关于我
        ├── projects.astro      # 项目页
        ├── 404.astro           # 404 页面
        └── posts/[slug].astro  # 文章详情页
```

## 二、本地开发命令

在 `blog` 目录下执行:

| 命令 | 作用 |
|------|------|
| `npm install` | 安装依赖(首次克隆后执行一次) |
| `npm run dev` | 启动本地预览,浏览器打开 `http://localhost:4321` |
| `npm run build` | 构建静态文件到 `dist/` 目录 |
| `npm run preview` | 预览构建产物 |

## 三、如何新增一篇文章

在 `src/content/posts/` 目录下新建一个 `.md` 文件,文件名就是网址路径(建议用英文或拼音,如 `my-first-post.md`)。

文件顶部是 frontmatter(用 `---` 包起来的字段),下面是正文:

```markdown
---
title: "文章标题"
description: "一句话摘要,显示在首页卡片上"
pubDate: 2026-10-29
tags: ["标签1", "标签2"]
---

这里是正文,支持 Markdown 语法。

## 二级标题

- 列表项
- 列表项

```js
// 代码块,自动高亮
console.log('hello');
```
```

**要点:**
- `title`、`description`、`pubDate` 是必填的,缺了会构建报错
- `tags` 可以省略(默认空)
- 保存后 `npm run dev` 会实时刷新;上线则推送到 GitHub

## 四、如何新增一个项目

在 `src/content/projects/` 下新建 `.md` 文件:

```markdown
---
title: "项目名称"
description: "项目简介"
link: "https://github.com/cqcdjz/项目地址"   # 可选,填了显示「查看 →」
tech: ["Astro", "Markdown"]                 # 可选,技术标签
---

项目详细介绍(可选)。
```

## 五、如何改样式

主题在 `src/styles/global.css` 里,改这些 CSS 变量就能换配色:

```css
:root {
  --bg: #0b1020;          /* 背景色 */
  --cyan: #22d3ee;        /* 青色强调 */
  --violet: #a78bfa;      /* 紫色强调 */
  --text: #e6e9f2;        /* 正文颜色 */
  --text-dim: #8a93b0;    /* 次要文字颜色 */
}
```

改完保存,`npm run dev` 实时生效。

## 六、如何改导航 / 页脚 / 关于我

| 想改的东西 | 改哪个文件 |
|-----------|-----------|
| 顶部导航的链接文字 | `src/components/Nav.astro` |
| 导航栏显示的博客名 | `src/components/Nav.astro` 里的 `logo` 链接 |
| 页脚版权信息 | `src/components/Footer.astro` |
| 「关于我」页的内容 | `src/pages/about.astro` |
| 首页的自我介绍 | `src/pages/index.astro` 的 `hero` 区块 |
| 浏览器标题栏(站点名) | 各页面里的 `BaseLayout title="..."` 以及 `Nav.astro` |

## 七、部署到 GitHub Pages(完整步骤)

你的博客地址将是:`https://cqcdjz.github.io`

1. **在 GitHub 上新建仓库**,仓库名务必填 `cqcdjz.github.io`(这样博客直接在根域名,不用加路径前缀)。

2. **本地推送代码**(在 `blog` 目录下):
   ```bash
   git remote add origin https://github.com/cqcdjz/cqcdjz.github.io.git
   git branch -M main
   git push -u origin main
   ```

3. **开启 Pages**:
   - 打开 GitHub 上这个仓库 → **Settings** → 左侧 **Pages**
   - 在 **Build and deployment** 的 **Source** 下拉框里选 **GitHub Actions**

4. **等待自动部署**:
   - 推送到 main 分支后,GitHub Actions 会自动跑构建并部署
   - 到仓库的 **Actions** 标签页能看到部署进度
   - 完成后访问 `https://cqcdjz.github.io` 即可看到博客

5. **以后更新文章**:本地写好后 `git add . && git commit -m "..." && git push`,就会自动重新部署。

## 八、常见问题

**Q: 构建报错 `title` / `description` 缺失?**
A: 文章或项目的 frontmatter 少了必填字段,按上面的格式补上。

**Q: 部署后页面样式乱了 / 图片 404?**
A: 多半是仓库名不是 `cqcdjz.github.io`。若用了别的仓库名(如 `blog`),需要改 `astro.config.mjs`,加一行 `base: '/blog/'`。

**Q: 想换博客主题色?**
A: 见第五节,改 `global.css` 里的变量即可。

**Q: 想加评论区、搜索、RSS?**
A: 这些当前没有(刻意保持简单)。要加的话告诉我,我帮你配。
